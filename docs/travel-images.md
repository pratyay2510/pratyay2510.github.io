# Travel Images Path Guide

This is the current source of truth for where to put travel images.

## Conventions

- Use lowercase names and hyphens.
- Use `.jpg` for best compatibility.
- Covers and card thumbnails use explicit `*-cover.jpg` paths.
- Do not use `.HEIC` in page image paths.
